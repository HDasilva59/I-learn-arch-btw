This project filters, reorganizes, translates, reformats, and enriches the command inventory. The synchronizer imports command names and source-page locations; it does not copy tldr page prose or examples into this application. The generated entries are marked as inventory references and should be checked against the linked tldr page, `--help`, and the local man page.
